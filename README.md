Un pequeño bot al estilo Nekos del personaje Shizuku. Contiene una lista básica de funciones para interactuar con el bot.

Nota: Este es solo el esqueleto, por razones personales el bot con las ultimas actualizaciones sera privado. Siéntanse libres de auditar o usar el código base.

## ◈ ADMIN
Comandos de administración del grupo básicas.
```
▸ ?quit    ⟶  Expulsa a un usuario del grupo
▸ ?reset   ⟶  Reinicia el bot
▸ ?setprefix ⟶  Cambia el prefijo del bot en el grupo actual
▸ ?welcome ⟶  Activa o desactiva el mensaje de bienvenida automática en el grupo
```

## ◈ UTILIDADES
Utilidades sencillas e interactivas para interaccion del grupo en general.
```
▸ ?cowsay  ⟶  Genera un cowsay como el programa original
▸ ?play    ⟶  Descarga audio o video de YouTube
▸ ?status  ⟶  Muestra el estado actual del bot
▸ ?sticker ⟶  Convierte imagen o video corto en sticker
```


## ◈ GENERAL
Informacion general
```
▸ ?menu    ⟶  Muestra todos los comandos disponibles al momento
▸ ?ping    ⟶  Verifica que el bot está activo
```
